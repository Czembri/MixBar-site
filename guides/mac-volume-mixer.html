What is a Mac volume mixer?

A Mac volume mixer gives each sound-producing application its own level and mute control. That solves a simple problem the standard macOS volume control does not: keeping a call clear while music, games, videos, and notifications run at different levels.

Updated October 15, 20267 minute readmacOS 14.2+

Does macOS have a built-in volume mixer?

macOS provides a master output volume and, in many apps, a volume control inside the app itself. It does not provide a Windows-style system panel with a separate slider for every application. If Spotify is too loud during a FaceTime call, the standard macOS control changes both together.

A third-party mixer fills that gap by identifying active audio processes, changing their relative gain, and sending the result to your selected output. Modern mixers can use Apple’s Core Audio process-tap APIs on macOS 14.2 or later instead of installing a kernel extension.

The useful distinctionMaster volume changes the complete output. Per-app volume changes one source while preserving the balance of everything else.

Apps and browser tabs are not the same

At the operating-system level, Chrome, Safari, or Opera normally appears as one application. Individual tabs need cooperation from the browser. MixBar uses optional browser extensions for supported tabs while preserving a browser-level master above them. Firefox remains controllable at the application level.

Tab support can also vary by playback method. Standard media elements are easier to control than protected streams, Web Audio-only pages, or embedded players. A credible mixer should state those limits rather than promise control over every page.

Why does a mixer request System Audio Recording?

Apple uses the “System Audio Recording” permission label for access to outgoing application audio. A mixer needs that access to process an app’s sound, even if it never creates or stores a recording. MixBar processes outgoing audio locally and in memory and does not capture microphone audio.

Driver-free versus virtual audio drivers

A virtual audio device is useful for advanced routing and recording workflows, but it adds another system component to configure. A process-tap mixer can provide everyday per-app control without permanently replacing the normal output device. Choose based on the job: complex studio routing may need a virtual device; daily volume balancing often does not.
