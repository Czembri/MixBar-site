Control individual Chrome tab volume on Mac

MixBar Tab Control is a Chrome tab volume control for Mac. It lets you opt specific playing tabs into separate volume, mute, and three-band EQ controls beneath a Chrome master.

Updated October 20, 20264 minute readChrome on macOS

Why macOS sees the whole browser

Multiple Chrome tabs share browser processes, so a normal per-app mixer can lower Chrome but cannot reliably know which page should change. Individual-tab control requires an explicit browser action that identifies and captures the tab you choose.

Install the reviewed companion extension

  1. Install MixBar Tab Control from the Chrome Web Store.
  2. Open MixBar on the Mac and complete its Browser Tabs setup.
  3. Play audio in the Chrome tab you want to control.
  4. Open the extension and choose Control this tab.
  5. The tab appears underneath Chrome in MixBar with its own volume, mute, and EQ.
No developer modeThe public extension is reviewed and installed from the Chrome Web Store. You do not need to load an unpacked extension or enable browser developer settings.

Keep the Chrome master

Controlled tabs appear as child sources under Chrome. The tab slider changes that page; the Chrome app slider remains a master for the browser. This makes it possible to keep a meeting tab clear, lower a playlist, and still mute all Chrome audio in one step.

What the extension accesses

The extension acts only after you choose a tab. It sends the captured tab’s audio to the local MixBar app through Chrome Native Messaging. It does not read page content, browsing history, bookmarks, passwords, form data, or microphone input. Audio processing happens locally in memory.

Pages that may behave differently

Protected streams, unusual embedded players, or browser policies can restrict capture. Stop controlling a tab before moving it between profiles or when a protected player refuses playback. The Chrome application itself remains available as a fallback source.

Remember settings by page

MixBar can restore a controlled tab’s saved volume, mute state, custom label, and EQ using its page URL. That is useful for recurring meeting pages, focus playlists, dashboards, and other sites you use repeatedly.

Put every playing tab in the right place.

The companion extension is free. Tab control is part of the MixBar Mac app.
