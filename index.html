Good to know

Questions, answered.

Why does MixBar need System Audio Recording access?

That is Apple’s name for the permission used to access an app’s outgoing audio stream. MixBar uses it only to change volume locally. Microphone audio is never requested or captured.

Does every browser support individual tab volume?

Safari works with standard HTML audio and video. Chrome and Opera use the optional MixBar extension and require you to choose which tabs to control. Firefox is controlled at the application level.

Will MixBar remember my settings?

Yes. App settings are stored by bundle identifier, while supported browser-tab settings are remembered by URL.

What is Audio Autopilot?

Audio Autopilot saves your complete mix as a scene and can activate it when an app plays, a website has media, a particular output is connected, or a time window begins. It restores the previous mix when the trigger ends, and all rules stay on your Mac.

Can every app, subprocess, and browser tab have different EQ settings?

Yes. Expand an app to reach each detected Core Audio subprocess, or open EQ beside a controlled Chrome or Opera tab. Bass, Mid, and Treble range from −12 dB to +12 dB, and MixBar remembers every curve.

Will it work with my Mac?

MixBar requires macOS 14.2 or later and includes native support for both Apple silicon and Intel Macs.

Does MixBar install an audio driver?

No. MixBar uses Apple’s built-in Core Audio process-tap technology. It does not install a virtual audio device, kernel extension, or system-wide driver.

What happens if an app cannot be processed?

MixBar is designed to leave the app’s normal audio path available if a tap cannot start or stops working, instead of leaving its sound muted.

Is this a subscription?

No. The license is a one-time purchase and includes all updates in the MixBar 1.x series.
