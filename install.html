Install MixBar from scratch.

Nothing important is hidden. Follow these steps in order and MixBar will explain each permission before macOS asks for it.

1. Install the app

  1. Open MixBar.dmg from Downloads.
  2. Drag MixBar onto the Applications shortcut.
  3. Eject the MixBar disk image, then open Applications and launch MixBar.
  4. Apple’s first-launch dialog should identify MixBar as notarized software. Choose Open.

2. Allow app-audio control

  1. Start music or video in any app.
  2. In the MixBar setup guide, choose Enable Audio.
  3. Approve System Audio Recording. Despite the name, MixBar does not use your microphone or save recordings.
  4. If access was denied earlier, open System Settings → Privacy & Security → System Audio Recording, enable MixBar, and relaunch it.

3. Choose your audio output

  1. Open Output and choose any available built-in, wired, Bluetooth, or AirPlay device.
  2. MixBar switches the macOS output directly and changes its icon to match the active route.
  3. If a newly connected device is missing, choose Refresh Audio Devices. Wireless drift compensation is enabled automatically.

4. Optional browser tab controls

Safari setup is built into MixBar: enable MixBar Tab Control in Safari’s Extensions settings and allow website access. For Chrome and Opera, install the reviewed MixBar Tab Control extension from the link shown inside the app. Customers do not need browser developer mode. Open MixBar → Settings → Browser Tabs and follow the browser-specific steps.

5. Everyday use

MixBar lives in the menu bar. Open it to adjust app and tab volume, mute, EQ, output, and AirPlay. Enable Start MixBar at login in Settings if you want it ready after every restart.
